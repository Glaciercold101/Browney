This is the exact flow from your starting list — polished with details.

Setup

📁 Link Folder & Refresh

Your notebooks live as real folders/files on disk — not in a database. This is what makes it portable and safe.

How to link

  • Click Link Folder in the top toolbar. Browser will ask for permission — choose your main notebook root folder.
  • Grant Edit access so auto-save can write JSON files directly.
  • Click the Refresh button at the top of the Notebooks tree (circular arrow). This re-scans the disk.
What gets created?

Each page = a .json file with content, type, images (or asset refs), timestamps. Safe to backup with Drive/Dropbox.

Why Refresh?

If you add files via Explorer/Finder or switch folders, Refresh rebuilds the tree without reloading the app.

Tip: Keep one master folder, e.g. /Browney/. Inside you can have many notebooks as subfolders. The app treats top-level folders as Notebooks.

📥 Import Pages

Bring in your existing work. Currently supports .one importers, HTML pages, and images.

Click Import Page in the toolbar. Select files from your computer.
Check first notebook — all imported pages land under the first notebook by default (to avoid scattering). A toast will say “Imported X pages ✓”
Move to destination Drag the imported files into the desired notebook/section. They auto-save in the new location.

Import details

  • OneNote (.one): Text, tables, images are converted. EMF diagrams are rasterized.
  • HTML: Keeps formatting, tables, code blocks. Wide tables scroll inside page, not per column.
  • Images: Drop or paste directly into WordPad — they become inline. Big images can be migrated later.

↕️ Drag & Move — Files, Folders & Notebooks

You may drag-move anything. No copy-paste needed.

Drag pages

Grab a page and drop between sections, into another notebook, or reorder inside same section.

Drag folders/sections

Move a whole section to another notebook. All child pages move with it.

Drag notebooks

Reorder notebooks in the sidebar. Your order is remembered.

Right-click tip

Right-click → Rename, Duplicate, Delete, Export. Delete goes to recoverable trash (see Safety).

✏️ View & Edit Files

Click on any file to view and edit. Edits are instant and auto-saved.

WordPad / Doc type

  • Rich text editing — headings, lists, tables, code blocks, checklists.
  • Drop or paste images directly anywhere. Images are stored inline in the JSON, or as migrated assets if large.
  • Table tools: Right-click table cells → add row/col, delete, Shift+Click to select cells → Merge.
  • Exportable cards — colored cards and exportable blocks for sharing.

Right-click Context Menu

This is your main command center. Right-click on any file/section/page:

  • Rename, duplicate, delete
  • Convert type (Doc → Sheet, etc.)
  • Add new page under same section
  • Table actions (when inside a table)
  • Export / Print (Live Reader)
Pro tip: The context menu is now fully expanded — no hidden buttons, scrolls to fit. If you don't see an option, scroll inside the menu.

💾 Auto-Save — All Files & Edits

There is no Save button. Everything auto-saves as you type.

  • Each page saves as JSON under your linked folder: Notebook/Section/pageId.json
  • Images inside docs are base64 inline (small) or migrated to __assets__ folder (big).
  • V132 safety: Recoverable trash, binary-safe copies, safe reload — the app rejects blank overwrites and never destructively compacts.
  • If you close the browser mid-edit, your last keystroke is already on disk.
Backup: Just zip your root folder or sync it with Google Drive / OneDrive. All your notebooks are plain files.

Custom templates

◫ Split Screen — Alt + Click

View two pages side-by-side without leaving your context.

Alt + Click on any file in the tree to open it on the right pane (split view).
Or click the Split View button in the top bar (icon: two rectangles). Then click pages to assign left/right.
Close split with the “Close Split” button at bottom of second pane, or click split button again.
Use cases: Copy from one doc to another, reference meeting notes while editing a sheet, compare two versions.

📦 Migrate Big Files & Images UPDATED • SELECTIVE

Click Migrate below to migrate big files images to a separate folder. Now you can choose which files to migrate.

When pages contain large images or attachments, the JSON can become huge and slow. Migrate extracts them to a separate folder and replaces them with lightweight references.

How to use (new flow)

Scroll to bottom of Notebooks tree → Click Migrate. The app scans all pages and lists pages with large embedded images/files with their size (e.g. 1.2 MB, 4.7 MB).
Choose which files to migrate — each file now has a checkbox. You can:
• Tick only the heavy pages you want to optimize
• Use Select All / Deselect All at top
• See file size, notebook location, and how many images it contains
• Leave small pages unticked — they stay inline for fastest access
Click Confirm Migrate. Only selected pages are processed:
• Extracts images to __assets__/{pageId}/ as separate files
• Page JSON is replaced with __ASSET__ references — loads faster, still displays inline
• Safe & reversible — original content backed up during migration
✅ Selective = safer

No more all-or-nothing. Migrate only that one 8MB OneNote import without touching your other notes.

⚡ Performance

Keep tiny pages inline (instant load), migrate only pages > 1-2 MB. Best of both worlds.

When to migrate? If a page loads slowly, or JSON file > 2-3 MB, run Migrate. Especially after bulk OneNote import. Now you can just tick those few big ones.
Tip: After selective migrate, click Refresh on top of the tree to see updated file sizes. If an image goes missing after moving folders, make sure you moved the page JSON + its __assets__ folder together.

🔷 Flow Charts & Diagrams (Offline)

Click to design Flow Charts and Diagrams. Works 100% offline.

Types

Flow Chart

Nodes, connectors, drag to reposition, resize handles, editable text (16px bold 3D style). Process steps, decisions, etc.

Diagrams

Org chart, horizontal org, matrix, pyramid, list blocks, bullet items, process steps — with 3D shadow and textured buttons.

How to use

  • Click New Flow Chart or New Diagram from New Page menu (or right-click → Add Page → Flow/Diagram).
  • Drag nodes, connect with lines, edit text inline.
  • Buttons have long shadow, rounded style (12px radius) inspired by your Style.jpg.
  • All data stored in flowData / diagramData inside JSON — offline, no external library needed.

📊 Spreadsheets & Charts

Two options: offline sheets and integrated online sheets. Both can be saved on the tree.

🟢 Offline Sheets (on 3-dots menu)

Path: Top-right 3 dots (🔴🟡🔵) → Spread Sheets (offline)

Opens ./offline-spreadsheets-charts/sheetsoffline.html. Full spreadsheet engine (Luckysheet) works offline. Create sheets, formulas, charts. Save — then import or link back as a Sheet page in your tree.

Best for: No internet, heavy calculations, local files.

🔵 Integrated Sheets & Charts (online)

Inside the app: New Page → Sheet or Chart type.

Integrated Luckysheet + chart board. Requires online for initial load, but then cached. Can be saved directly on the tree as a page (type: sheet). Chart board preview renders HTML.

Best for: Keeping sheets alongside docs in same notebook, with auto-save.

Charts

  • New Page → Chart type → choose bar, line, pie, etc.
  • Data can be typed or linked from a Sheet page.
  • Preview renders as HTML block inside page.

🛡️ Data Safety & Recovery

V132 hardening: recoverable trash, binary-safe copies, safe reload.

  • Recoverable Trash: Deleted pages are not wiped immediately — check .trash or __trash__ folder in your linked directory.
  • Binary-safe copies: Assets are copied with binary-safe method to avoid corruption.
  • Blank overwrite protection: App rejects empty saves that would erase content (e.g., if editor fails to load).
  • No destructive compaction: Old versions are not auto-pruned.
  • Auto-save is atomic: Each save writes to temp then renames — never half-written files.
Best practice: Enable File History or versioning on your OS for the linked folder. Even if something goes wrong, you can restore a previous JSON.

❓ FAQ

Where are my files actually stored?

Inside the folder you linked. Each page is a JSON file. Example: D:/MyNotebooks/Work/Meetings/2026-05-01.json. Images inside that JSON or in __assets__. You own everything.

Can I use it offline?

Yes — docs, flow charts, diagrams, offline sheets, kanban all work offline. Only the integrated online sheets/charts need internet on first load.

Why do imports go to first notebook?

To keep imports predictable. You can then drag to the right place. This avoids accidental scattering across notebooks.

Images not showing after move?

Click Refresh on top of tree. If still missing, check if page was migrated — assets folder must move with JSON. Keep JSON + its asset folder together.

Split screen not working?

Hold Alt and click. On Mac, use Option + Click. Or click the split view icon in toolbar first.

How to backup?

Zip the root linked folder. Or sync it with OneDrive/Dropbox/Git. No export needed — the folder IS the backup.
